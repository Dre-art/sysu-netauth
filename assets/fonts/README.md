# Noto Serif SC

`NotoSerifSC-Regular.ttf` is the static 400-weight instance of the Google Fonts
[Noto Serif SC variable font](https://github.com/google/fonts/tree/main/ofl/notoserifsc),
retaining its complete character coverage. The instance was produced with
`fonttools varLib.instancer` with `wght=400` and name table updates.

The font is distributed under the SIL Open Font License 1.1; see
[OFL-NotoSerifSC.txt](OFL-NotoSerifSC.txt). It is loaded privately by the GUI
process and is not installed as a system font.
